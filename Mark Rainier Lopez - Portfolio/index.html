PROJECT 01 / IOT • EMBEDDED SYSTEMS

Smart Silong

An IoT-based smart clothing rack that monitors its surroundings and can be watched and controlled from a phone, powered by solar energy.

CategoryIoT / Embedded
Core boardESP32
InterfaceBlynk mobile app
PowerSolar

The problem

Drying laundry outdoors depends on weather that can change quickly. The goal was a rack that senses its environment and reports conditions, so the user is not guessing.

How it works

Sensors measure temperature and humidity (DHT11), rain (YL-83), and air quality (MQ-135). The ESP32 reads them, sends the data to Blynk for real-time monitoring, and accepts remote commands for control and automation. A solar supply keeps the system energy-efficient.

Key features

  • Real-time mobile monitoring
  • Remote control and automation
  • Environmental sensor integration
  • Energy-efficient, solar-powered operation

What I learned

  • Wiring and calibrating multiple sensors on one microcontroller
  • Building an IoT dashboard and device-to-cloud communication
  • Designing around a limited power budget

PROJECT 02 / FULL-STACK WEB DEVELOPMENT

Magic Scheduler

A full-stack event management web application for organizing magic performance bookings, clients, schedules, locations, performers, and payments.

CategoryFull-stack web
FrontendReact
BackendNode.js / Express
DatabaseMongoDB

The problem

Running a performance business means juggling bookings, client details, performer availability, venues, and downpayments. Doing this by hand or across chats is easy to get wrong.

How it works

A React dashboard talks to a Node.js and Express REST API backed by MongoDB. Events appear on a calendar, each tied to a client, performer, location, and payment status, and the system calculates travel distance to the venue.

Key features

  • Event scheduling and calendar management
  • Client and performer management
  • Payment and downpayment tracking
  • Location and distance calculation
  • Responsive dashboard and mobile layout

What I learned

  • Designing a data model that links events, clients, performers, and payments
  • Building and consuming a REST API end to end
  • Making a data-heavy dashboard usable on mobile

PROJECT 03 / DIGITAL ELECTRONICS

Miniature Traffic Light

A hardware-based traffic light system that uses a 555 timer and a 7474 flip-flop for sequential signal control, with no microcontroller.

CategoryDigital electronics
Timing555 Timer
Logic7474 Flip-Flop
OutputRed / Yellow / Green

The problem

The challenge was to control a traffic signal sequence using only discrete digital logic, showing how timing and state can be built from basic components.

How it works

The 555 timer provides the clock pulses that set the timing. The 7474 flip-flops hold the current state and step through the sequence, driving the red, yellow, and green signals in order.

Key features

  • Sequential timing circuit
  • Red / Yellow / Green signal sequence
  • Built entirely from digital logic ICs

What I learned

  • Applying timing and sequential logic in a real circuit
  • Debugging hardware step by step with test equipment
  • Turning a theory topic into a working demo
